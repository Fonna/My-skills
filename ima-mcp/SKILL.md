# ima MCP

通过本地 stdio 适配器连接 `https://ima.qq.com/mcp`。首次授权或续期需要**同一台电脑上正在运行、已登录且已连接 ima 的 WorkBuddy**。专用 MCP 令牌使用 Windows DPAPI 加密保存，之后可关闭 WorkBuddy。每台电脑分别授权，不复制令牌。

## 接入与诊断

安装或迁移时阅读 [README.md](README.md)。运行 `node <本技能目录>/scripts/auth.mjs login` 获取并缓存授权；`doctor.mjs --standalone` 检查完全不访问 WorkBuddy 时的 MCP 连接，加 `--read-test` 才读取一条资料。安装脚本会复制本技能并注册 `ima` 服务；只复制技能文件不会自动注册 MCP。重启 Codex 后加载。

不要以 ima OpenAPI/API Key 或猜测的 OAuth 地址替代这个连接器。认证失败时打开 WorkBuddy，检查登录与 ima 连接，再执行 `auth.mjs login`；账号切换后也需重新获取授权。实际到期时间以 `auth.mjs status` 为准，服务端可能提前撤销。当前不是 Codex 独立 OAuth；WorkBuddy 的内部 WBIPC 协议变动时可能需要更新取授权流程。

## 调用

- 以本次 `tools/list` 的工具名、参数与能力为准。当前包含查库、库内检索、读取正文、可添加知识库列表、网页导入和文件入库；没有创建知识库、重命名、移动、删除既有条目的工具。
- 先查库得到真实库 ID，再检索或列举条目得到 `media_id`，需要正文时再读取。返回的库对象可能使用 `id`，传入参数使用 `knowledge_base_id`，按实际回执取值，不拼接 ID。
- 未指定范围时按需要覆盖我的、共享和订阅库；检索是单库操作，跨库分别查并说明范围。保留游标，单页结果不代表全量。
- 回答关于用户资料的问题前先检索；依据正文回答并保留标题和可用来源链接。无权限、未解析、空结果分别说明。
- 写入前用可添加知识库列表确认目标；目标或内容不明确时先询问。授权接入不代表授权测试写入。
- 网页导入遵循服务端批量上限；文件入库依次完成创建媒体、按返回方式上传、添加知识。只申请媒体不算入库，收下资料也不代表解析完成。
- 不自动重试写操作。超时后先核实是否已成功，避免重复入库。鉴权错误引导重新连接，权限拒绝不换账号绕行。

适配器只对 MCP HTTP `401` 且取得不同令牌时重试一次；不重试 `403`、网络异常或已执行的业务错误。令牌只存在于进程内存和本机 DPAPI 加密缓存中，不写入配置、日志或仓库。设置 `IMA_MCP_WORKBUDDY=never` 时禁止自动向 WorkBuddy 获取令牌。
